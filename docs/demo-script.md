# Demo script

## Demo 1 (3 minutes): Prompt-only
Ask: "Build a domain registration API for hosting customers."
Discuss unstated assumptions: ownership, duplicate domains, error handling and testing.

## Demo 2 (6 minutes): OpenSpec + MCP
1. Read openspec/specs/domain-management.md.
2. Have the coding agent inspect this repository using GitHub MCP.
3. Ask it to summarize acceptance criteria before editing.
4. Run the tests.
5. Read openspec/changes/transfer-domain/proposal.md.
6. Request an impact analysis and implementation plan.

## Backup plan
If the model or internet fails, use committed code, specs and tests.
